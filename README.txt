Elden RPG - تطبيق قابل للتثبيت
==============================

الملفات (ارفعها كلها معاً في المجلد نفسه):
  index.html              التطبيق نفسه
  manifest.webmanifest    بيانات التثبيت
  sw.js                   يجعل التطبيق يعمل بلا إنترنت
  icon-*.png              الأيقونات

نشره مجاناً على GitHub Pages:
  1. أنشئ حساباً على github.com ثم مستودعاً جديداً (New repository) باسم مثل elden-rpg.
  2. اضغط "Add file" ثم "Upload files" وارفع كل الملفات أعلاه، ثم Commit.
  3. من Settings ثم Pages: اختر Branch = main والمجلد = (root) ثم Save.
  4. بعد دقيقة يظهر رابطك: https://اسم-حسابك.github.io/elden-rpg/
  5. افتح الرابط من هاتفك:
       أندرويد (Chrome): القائمة ثم "تثبيت التطبيق".
       آيفون (Safari): المشاركة ثم "إضافة إلى الشاشة الرئيسية".

مهم: بياناتك تُحفظ داخل المتصفح لكل رابط على حدة.
  - قبل الانتقال إلى الرابط الجديد: من النسخة القديمة صفحة "العهد" ثم "تصدير البيانات".
  - في النسخة الجديدة: "العهد" ثم "استيراد البيانات".
  - للنقل بين هاتفك وحاسوبك استخدم التصدير والاستيراد نفسهما.
